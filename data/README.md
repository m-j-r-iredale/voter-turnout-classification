# Data

This project uses the 2022 Cooperative Election Study.

The source dataset is not committed to this repository. The original project began with a file containing approximately 60,000 observations and 706 columns.

To run the scripts, place the cleaned CES CSV file at:

```text
data/CCES22_Common_OUTPUT_vv_topost_Clean.csv
```

The code expects the original CES variable names used in the project, including the response variable `CC22_363` and the nine final-model predictors.

Do not commit the survey CSV to the repository unless its distribution terms explicitly permit redistribution.
